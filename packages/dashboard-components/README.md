# @uspot-leb/dashboard-components

Reference React components for the USpotLeb dashboard.

> **Prefer the CLI.** The recommended workflow is to copy editable source into your project:

```bash
npx @uspot-leb/dashboard-cli init
```

This package exists for shared types/utilities and advanced consumers who want a published dependency. For maximum flexibility (shadcn-style ownership), use the CLI generator instead.

## Install

```bash
npm install @uspot-leb/dashboard-components lucide-react recharts clsx tailwind-merge
```
